# France Foot 2D / Super Soccer World — 00.03.00 build 14

Le téléchargement contient deux dossiers : `FranceFoot2D_v00.03.00_build14` (jeu Windows 64 bits, lancez FranceFoot2D.exe) et `FranceFoot2D_v00.03.00_build14_Source` (code source complet). Format de sauvegarde inchangé.

## Hymnes nationaux
- Orchestration refaite : cuivres doublés, cordes qui tiennent les accords (I, IV, V), basse, timbales, cymbale finale et réverbération de stade.
- Deux hymnes réels ajoutés : Russie et Canada (God Save the King est aussi utilisé par le Liechtenstein).
- Six hymnes originaux (marche, solennel, choral, fanfare, lyrique, populaire) remplacent l'hymne générique unique : chaque sélection sans hymne connu reçoit toujours le même.

## Supporters et ambiance
- Quatre nouveaux chants : chant du club lent et repris par tout le stade, clapping viking qui s'accélère, batucada avec tambours, comptine moqueuse quand l'équipe mène. Les chants s'enchaînent selon l'humeur du public sans se répéter.
- La ola fait le tour du stade quand l'ambiance est bonne, avec sa clameur.
- La rumeur du stade enfle quand une équipe approche du but et explose sur les buts.
- Applaudissements pour les arrêts du gardien local et pour les joueurs remplacés ; flashs des téléphones dans les tribunes en nocturne.

## Captures d'écran
F12 (ou Impr. écran) : l'image du jeu est enregistrée en PNG (1280 x 720) dans le dossier `captures` à côté de FranceFoot2D.exe. Un message confirme le nom du fichier.

## Homme du match
Match télévisé : à la fin de la rencontre, la chaîne désigne l'homme du match (bandeau avec le joueur, sa note sur 10 et ses statistiques marquantes). La note tient compte des buts, passes décisives, passes réussies, tacles, interceptions, tirs contrés, arrêts, du résultat, des clean sheets et des cartons. L'homme du match est aussi indiqué sur l'écran de résultat de tous les matchs.

## Vestiaires
Avant le match, à la mi-temps et après le match, l'équipe dirigée par le joueur passe par le vestiaire : casiers avec les maillots et les noms des titulaires, tableau tactique, banc, entraîneur qui parle, réponse du capitaine. Trois discours au choix :
- avant le match : calme (mentalité un cran plus prudente), combat, ou « mettre le feu » (un cran plus offensive) ;
- à la mi-temps : garder le cap, remobiliser (+3 % d'endurance), hausser le ton (un cran plus offensive) ;
- après le match : discours sans effet sur le jeu ; fête avec champagne et chants après une victoire, trophée sur la table après un titre, têtes basses après une défaite.
Option « Scènes de vestiaire » dans les Options pour les désactiver.
